# Task Structure — Full Documentation

## Task Input Order

Here's the order you'll see in each task (when applicable):

1. **System Prompt** (if available) — defines the AI's behavior/persona
2. **Conversation History** (if available) — prior user–assistant dialog
3. **User Prompt** — may include reference text depending on the task category
4. **Two model responses** — evaluate them using the full context above

## How to Evaluate

When evaluating responses, consider the full context: System Prompt, Conversation History, and User Prompt (which may include reference text).

Using that context, determine whether each response has issues, then state which response you prefer and why.

## What Stays the Same

- The rating dimensions remain unchanged across task categories
- The overall task flow remains unchanged
- Always evaluate using the full context

## Task Categories

Task categories vary by batch. Examples include:
- Coding
- Writing
- Reasoning
- Others as assigned
