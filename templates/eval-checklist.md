# Eval Checklist Template

Use this checklist when evaluating a task.

## Before Evaluating

- [ ] Read the System Prompt (if present) — note the AI's role and constraints
- [ ] Read the Conversation History (if present) — understand prior context
- [ ] Read the User Prompt — identify exactly what is being asked
- [ ] Note any reference text included in the User Prompt

## Evaluating Response A

- [ ] Does it follow the System Prompt (if present)?
- [ ] Does it correctly use context from the Conversation History?
- [ ] Does it accurately address the User Prompt?
- [ ] Are there any factual errors or hallucinations?
- [ ] Is the format/style appropriate?
- [ ] Any other issues?

## Evaluating Response B
